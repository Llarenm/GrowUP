# GrowUP

## Descripción
GrowUP es una plataforma web educativa diseñada para orientar a estudiantes en la elección de su carrera profesional mediante test vocacionales y recursos informativos.

## Instalación
1. Clonar el repositorio:
git clone https://github.com/tu-usuario/growup.git

2. Abrir el archivo index.html en el navegador

## Uso
1. Acceder a la plataforma desde el navegador
2. Completar el test vocacional
3. Consultar los resultados y recomendaciones de rutas personalizadas

## Tecnologías
- HTML5
- CSS3
- JavaScript (Vanilla)
